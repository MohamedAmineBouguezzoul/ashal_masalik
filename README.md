# أسهل المسالك - مساعد الحفظ والضبط 📚

تطبيق ويب تفاعلي حديث مصمم خصيصاً لمساعدة طلاب العلم على حفظ وضبط وفهم **منظومة أسهل المسالك في مذهب الإمام مالك** للشيخ محمد البشار. يوفر التطبيق تجربة تعليمية متميزة تجمع بين جماليات التصميم العصري والأدوات العلمية المتطورة لتثبيت الحفظ والمراجعة.

---

## 🌟 مميزات التطبيق الرئيسية

### 1. لوحة التحكم والمتابعة التفاعلية (Dashboard)
* **إحصائيات التقدم**: رسم بياني دائري متطور يوضح النسبة المئوية للحفظ العام وتفاصيل الأبيات المحفوظة بالكامل أو قيد الحفظ.
* **استئناف الحفظ**: زر ذكي يقوم بحفظ آخر نقطة توقف والعودة إليها بنقرة واحدة.
* **متابعة الأبواب**: عرض سريع لجميع أبواب المنظومة الفقهية مع نسبة إنجاز تفصيلية لكل باب.

### 2. المراجعة الذكية بالتكرار المتباعد (Spaced Repetition System - SRS)
* نظام ذكي مدمج يقوم بجدولة مراجعة الأبيات المحفوظة تلقائياً لضمان عدم نسيانها.
* خيارات تقييم تفاعلية بعد التسميع الذاتي:
  * **سهل**: يباعد فترة المراجعة القادمة تصاعدياً (`1` ➔ `3` ➔ `7` ➔ `14` ➔ `30` ➔ `60` ➔ `90` يوماً).
  * **متوسط**: يُبقي على نفس الفترة الزمنية الحالية لإعادة مراجعتها لاحقاً.
  * **صعب / نسيت**: يُعيد جدولة البيت فوراً ليوم الغد لترسيخه مجدداً.

### 3. تصفح المتن المتقدم (Poem Browser)
* **أدوات التظليل والإخفاء**: إمكانية إخفاء الصدر أو العجز أو كلمات عشوائية في الأبيات واختبار النفس بلمسة واحدة.
* **التحكم بالتشكيل**: زر مخصص لإخفاء/إظهار الحركات الإعرابية (التشكيل) لتسهيل القراءة أو الاختبار.
* **البحث السريع الذكي**: محرك بحث متطور يتجاهل الحركات الإعرابية والترقيم ويقوم بفرز ومطابقة النصوص العربية فوراً أثناء الكتابة.
* **تسريع وتيرة تحديد الحفظ**:
  * **التعديل السريع المباشر**: إمكانية تغيير حالة حفظ البيت (غير محفوظ ➔ قيد الحفظ ➔ محفوظ) بنقرة واحدة مباشرة على شارة الحالة في قائمة الأبيات دون الحاجة لفتح الدرج الجانبي.
  * **أزرار التنقل في درج التفاصيل**: أزرار "التالي" و "السابق" داخل الدرج الجانبي للتنقل السريع والسهل بين الأبيات المتتالية.
  * **اختصارات لوحة المفاتيح**: تسهيل وتسريع الحفظ عبر التحكم بالدرج الجانبي بلوحة المفاتيح:
    * الأسهم (⬅️/➡️ أو ⬆️/⬇️) للتنقل للبيت التالي/السابق (وكذلك مفاتيح `N` للتالي و `P` للسابق).
    * الأرقام `1` و `2` و `3` (أو `١` و `٢` و `٣`) لتعديل حالة الحفظ مباشرة (غير محفوظ ➔ قيد الحفظ ➔ محفوظ).
    * مفتاح `Esc` لإغلاق الدرج فوراً.

### 4. الروابط الذهنية الذكية وكاشف المتشابهات اللفظية (Smart Mnemonics)
* **رابط السرد والانتقال**: يقوم التطبيق تلقائياً باستخراج الكلمة الأخيرة من البيت الحالي والكلمة الأولى من البيت التالي لتسهيل انتقال الذهن أثناء التسميع الشفهي.
* **كاشف المتشابهات**: تنبيه ذكي يظهر فوراً باللون الأحمر للتحذير من أي أبيات أخرى في المنظومة تبدأ بنفس الكلمات لمنع التداخل والخلط بين الأبيات.

### 5. وضع التركيز والتسميع التلقائي (Focus Mode)
* عرض بيت واحد في الشاشة بحجم خط كبير ومريح للعين.
* **التشغيل التلقائي (Autoplay)**: تشغيل المتن سردياً وبشكل تلقائي مع إمكانية ضبط السرعة (4 أو 6 ثوانٍ لكل بيت) للتلقين والحفظ بالاستماع أو التكرار البصري.
* إخفاء الصدر أو العجز بشكل مخصص داخل وضع التركيز.

### 6. خمسة أوضاع للاختبارات (Interactive Quiz)
* **أكمل العجز**: اختر التكملة الصحيحة لعجز البيت من بين خيارات متعددة.
* **أكمل الصدر**: اختر التكملة الصحيحة لصدر البيت.
* **الكتابة اليدوية**: اكتب الشطر الناقص يدوياً مع مصحح إملائي مرن يراعي الفروق الإملائية الطفيفة في الكتابة العربية.
* **توصيل الأشطار**: صل بين صدور الأبيات وأعجازها بشكل تفاعلي.
* **ترتيب الأبيات**: رتب الأبيات المتتالية ترتيباً تصاعدياً صحيحاً حسب ورودها في المتن.

## 🛠️ التقنيات المستخدمة

تم بناء التطبيق بالكامل باستخدام تقنيات الويب الأساسية دون أي اعتماد على خوادم خارجية أو قواعد بيانات معقدة لضمان الخصوصية والسرعة الفائقة:
* **الهيكل**: HTML5 (دلالي ونظيف).
* **التنسيق**: CSS3 (مظهر عصري، يدعم الوضعين الداكن والفاتح، متوافق مع شاشات الهواتف والأجهزة اللوحية).
* **المنطق والتحكم**: Vanilla JavaScript (ES6+).
* **قاعدة البيانات**: ملف `data.js` يحتوي على المتن كاملاً (1158 بيتاً) مقسماً حسب الأبواب الفقهية، مع الشرح المفصل للكلمات الغامضة والمعاني الفقهية للأبيات.
* **حفظ البيانات**: يتم تخزين تقدم الحفظ وجدول المراجعة محلياً في المتصفح باستخدام `LocalStorage`.
